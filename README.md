# Retail Sales Analysis## Analyse exploratoire des ventes d'une entreprise de commerce en ligne### Présentation du projet**Retail Sales Analysis** est un projet personnel de Data Science consacré à l'analyse exploratoire de données transactionnelles provenant d'une entreprise britannique spécialisée dans le commerce en ligne.À partir du jeu de données *Online Retail*, ce projet vise à exploiter les données de ventes afin de mieux comprendre les performances commerciales, d'identifier les produits et les marchés les plus performants et d'étudier le comportement des clients.L'analyse a été réalisée avec Python, en suivant plusieurs étapes : exploration des données, nettoyage, traitement des anomalies, analyse statistique et visualisation des résultats.### Objectifs- Explorer et comprendre la structure du jeu de données.- Identifier et traiter les valeurs manquantes.- Repérer les transactions invalides et examiner les annulations.- Étudier l'évolution mensuelle des ventes.- Identifier les produits générant les montants de ventes les plus élevés.- Analyser les performances commerciales par pays.- Étudier les principaux clients et les montants des commandes.- Détecter les valeurs extrêmes et mesurer leur influence sur les indicateurs statistiques.- Présenter les résultats à l'aide de visualisations.### Technologies et outils utilisés| Technologie | Utilisation ||---|---|| Python 3.12 | Langage de programmation || Pandas | Manipulation et analyse des données || NumPy | Calculs numériques || Matplotlib | Création des visualisations || OpenPyXL | Lecture du fichier Excel || Spyder | Environnement de développement |### Source des donnéesLe projet utilise le jeu de données **Online Retail**, disponible sur le [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/352/online+retail).Le fichier initial contient **541 909 lignes et 8 colonnes**, couvrant la période de décembre 2010 à décembre 2011.Les principales variables sont :- `InvoiceNo` : numéro de facture.- `StockCode` : référence du produit.- `Description` : description du produit.- `Quantity` : quantité achetée.- `InvoiceDate` : date de la transaction.- `UnitPrice` : prix unitaire.- `CustomerID` : identifiant du client.- `Country` : pays du client.### Structure du des premières observations.2. **Nettoyage** : identification des valeurs manquantes, des quantités négatives, des prix non valides et des factures d'annulation.3. **Traitement des annulations** : rapprochement de certaines lignes de vente avec des lignes d'annulation à partir de plusieurs critères, notamment le client, le produit, la quantité et le prix.4. **Analyse exploratoire** : étude des ventes par mois, produit, pays et client.5. **Analyse statistique** : étude des montants des commandes et identification des valeurs extrêmes.6. **Visualisation** : représentation graphique des principaux résultats.**Précaution méthodologique :** le rapprochement automatique des ventes et des annulations a permis d'identifier 2 910 lignes candidates. Ces correspondances ne sont pas toutes des annulations confirmées. Certaines associations nécessitent une vérification supplémentaire, notamment lorsqu'une différence de prix est constatée.### Résultats principauxAprès le processus de nettoyage et de traitement retenu :| Indicateur | Résultat ||---|---:|| Nombre de lignes initiales | 541 909 || Lignes conservées | 527 193 || Montant des ventes positives conservées | 10 203 599,53 £ || Part du Royaume-Uni dans les ventes positives | 84,29 % || Nombre de factures clients identifiées | 18 397 || Montant moyen d'une commande | 460,38 £ || Montant médian d'une commande | 302,10 £ || Montant maximal d'une commande | 27 872,80 £ |**Quelques observations :**- Novembre 2011 est le mois présentant le montant de ventes positives le plus élevé, avec environ **1 493 640,62 £**.- Le Royaume-Uni représente la plus grande part des ventes positives conservées.- Le produit physique ayant généré le montant de ventes le plus élevé est *REGENCY CAKESTAND 3 TIER*.- La moyenne des montants des commandes est supérieure à la médiane, ce qui met en évidence l'influence de commandes de montants particulièrement élevés.- 1 451 commandes ont été identifiées comme valeurs extrêmes selon la méthode de l'intervalle interquartile.**Important :** les montants présentés correspondent aux ventes positives conservées après nettoyage. Ils ne représentent ni le chiffre d'affaires net comptable ni le bénéfice, car le jeu de données ne contient pas les coûts des produits.### VisualisationsLes graphiques produits au cours de l'analyse sont disponibles dans le dossier `figures/`.Exemples de visualisations :- Évolution mensuelle des ventes.- Top 10 des produits par montant de ventes.- Top 10 des produits physiques par montant de ventes.- Répartition des ventes par pays.- Top 10 des clients.- Distribution des montants des commandes.### Rapport détailléLe rapport complet présentant la méthodologie, les résultats, les observations et les limites de l'analyse est disponible ici :[`reports/rapport_analyse.md`](reports/rapport_analyse.md)### Installation et exécution1.
